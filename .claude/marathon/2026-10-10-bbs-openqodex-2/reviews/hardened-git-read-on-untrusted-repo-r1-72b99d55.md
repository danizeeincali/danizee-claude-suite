## High (2)

- **Filter drivers and core.attributesFile in config.worktree are never discovered, so their clean filter runs** — `.claude/helpers/kit/safe-git.js:179` (security): Driver discovery reads only \`git config --local\` (.git/config plus includes). With extensions.worktreeConfig=true, git also reads $GIT\_DIR/config.worktree, and \`--local\` does not see it. Traced on git 2.43: in an untrusted repo, \`git config --worktree filter.evil.clean "sh -c 'touch PWN; cat'"\` plus \`git config --worktree core.attributesFile .git/evilattrs\`, where .git/evilattrs is \`\* filter=evil\` (inside .git, which the .gitattributes walk skips). Then modify a tracked file and run \`node cli.js safe-git --dir r1 -- diff\` (or \`status\`). The name \`evil\` is not in the override list, and the clean filter runs and creates PWN. The same gap applies to a linked worktree, whose config.worktree lives in .git/worktrees/\<x\>/. In that case the code also reads gitDir/info/attributes, not commonDir/info/attributes. — fix: Read every config git will use, apart from system and global: use \`git config --includes -z --get-regexp\` without --local under the hardened env, which excludes system and global, or add \`--worktree\`. Look up core.attributesFile the same way. Read info/attributes from the common dir. Add a test with a filter set in config.worktree.
- **Abbreviated long options bypass the deny-list (cat-file --textc runs textconv)** — `.claude/helpers/kit/safe-git.js:218` (security): checkReadArgs matches the denied options exactly. git's parse-options accepts any unambiguous prefix, and cat-file adds no --no-textconv because it is not in DIFFING. Traced: in a repo with \`diff.tc.textconv = sh -c 'touch PWN2; ...'\` set in its local config and \`\* diff=tc\` in .gitattributes, \`node cli.js safe-git --dir r2 -- cat-file --textc HEAD:f.txt\` exits 0 and creates PWN2, which means the repo's own command ran. The exact \`--textconv\` form is refused, as the test at line 92 checks, but the abbreviated form is not. — fix: Refuse any option that is a prefix of a denied long option (for each long option, check \`name.startsWith(arg.split('=')\[0\].slice(2))\` with a length of at least 3). Also override \`diff.\<name\>.textconv=\` for every \`diff=\` driver named in the attributes, as already done for filters. Add tests for \`cat-file --textc\` and \`--textconv\` abbreviations.
