- **Lens step feeds \`git diff HEAD\`, which misses committed branch/PR work and untracked files** — `.claude/commands/.shortcuts/w-review.md:83` (correctness): /w-review is invoked as \`/w-review \[PR number or description\]\`, but the lens step always runs \`git diff HEAD \> /tmp/w-review.diff\`. When the change under review is already committed (a PR or branch: the normal case), that diff is empty; brand-new files that are not yet \`git add\`ed are also left out. Traced in a temp repo: after committing a change that adds \`await fetch(u)\` to src/a.js and an \`it(...)\` test, \`git diff HEAD | lenses --diff -\` returns changed\_files 0, fired \[\] and exit 0, so the reviewer records 'no lens applies' for a change that should fire missing-await and test-asserts-nothing. Same text is in src/plugins/dot-shortcuts.js (~line 2121). — fix: Diff against the review base, e.g. \`git diff $(git merge-base HEAD \<base\>)\` (or \`gh pr diff \<N\>\` for a PR number), and include untracked files (\`git add -N\` or \`git diff --no-index\`); tell the reviewer to treat changed\_files 0 as 'wrong input', not 'no findings'. Update the test regex in test/w-review-command.test.js to match.
- **Diff paths keep \`c/\`/\`i/\`/\`w/\` prefixes under diff.mnemonicPrefix, so directory-anchored globs silently miss** — `src/lib/kit/lenses.js:216` (correctness): The \`diff --git\` regex only recognises \`a/\` and \`b/\`, and cleanPath only strips \`\[ab\]/\`. The w-review step runs a bare \`git diff HEAD\`, which honours the user's diff.mnemonicPrefix (or diff.srcPrefix/dstPrefix) config. Traced: with \`git -c diff.mnemonicPrefix=true diff HEAD | lenses --diff -\` the reported files are \`w/src/a.js\` and \`w/test/b.test.js\`. Any glob containing a \`/\` is anchored at the root (\`test/\*\*/\*.js\`, \`src/\*\*/\*.ts\`, typical project lenses), so it never matches \`w/test/...\` and the lens silently does not fire, with exit 0. (Only basename globs like \`\*\*/\*.js\` survive.) — fix: Pin the prefixes where the diff is produced (\`git diff --no-color --no-ext-diff --src-prefix=a/ --dst-prefix=b/ ...\` in w-review.md and dot-shortcuts.js), and/or have the parser derive the path from the \`+++\`/\`---\` lines after stripping a single \`\[a-z\]/\` prefix that matches the diff --git header. Add a parseDiff test with mnemonic prefixes.
