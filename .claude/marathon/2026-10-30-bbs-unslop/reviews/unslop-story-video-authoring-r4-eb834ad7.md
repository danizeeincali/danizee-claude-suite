HANDLER only matches an attribute that follows whitespace (\s+on...), and TAG (line 133) fails to match a tag whose unquoted value holds '\<'. Probe: a --page body with \`\<img/onerror="fetch('http://example.com/x')" src=x\>\`, \`\<img src=x y=\< onerror="fetch('http://example.com/y')"\>\` and \`\<img src="x"/onerror=alert(2)\>\` comes out of \`story-plan emit\` unchanged. So page script runs in a page the docs call script-free. That makes the frames nondeterministic, can reach localhost (story-render allows it), and has open egress when the page is opened by hand through story-render play. I graded this medium, not high: the input is the author's own page, and story-render blocks hosts that are not local. — fix: Match a handler after whitespace or '/' (e.g. (?:\s|/)+on\[a-z\]+ ...), and when TAG cannot parse a tag (an unquoted value holds '\<' or a stray quote), drop any on\[a-z\]+= in that tag text with a fallback pass. Add these three probes to the strip test.

Add a test for a body-level meta refresh and base.
