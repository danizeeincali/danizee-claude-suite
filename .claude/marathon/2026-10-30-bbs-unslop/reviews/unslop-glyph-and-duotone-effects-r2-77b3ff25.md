- **A failing shimmer tick is restarted by the next sync, and fallback never stops the timer** — `src/lib/kit/image-effects.js:218` (correctness): tick() catches its own error and calls stop(), but sync() is still wired to visibilitychange, the reduced-motion change event and the IntersectionObserver. The next tab switch or scroll back on screen restarts setInterval, which throws again on every 100 ms tick. fallback() also removes the canvas without clearing the timer or the listeners, so a shimmer that has started keeps drawing up to 2000 cells per tick onto a detached canvas. — fix: Add a dead flag: tick's catch and fallback() both set it and call stop(), and sync() returns early when it is set.
- **Syntactically invalid selectors pass validation and give a silent no-op snippet** — `src/lib/kit/image-effects.js:130` (correctness): checkSelector checks only the character set and that brackets and quotes balance. The user gets a snippet that does nothing, with no error from the kit and no console message. — fix: Refuse a leading or trailing combinator or comma, an empty compound between commas, and '::' with no name (exit 1). Or have the emitted script console.warn when querySelectorAll throws.
- **--chars made only of whitespace is accepted and hides the main image** — `src/lib/kit/image-effects.js:147` (correctness): checkChars counts code points and refuses control characters only. --chars ' ' (probed) or a ramp of zero-width characters exits 0.
