## High (1)

- **Pi Brain POST redacts the JSON-encoded body, so a secret with a quote, backslash or control character is posted unredacted** — `src/plugins/dot-shortcuts.js:3711` (security): CHECKPOINT 7 of w-compound has the lead write the JSON body to $E and pipe that JSON text through \`redact --keep-lines\`. redact matches the raw secret bytes, but JSON.stringify escapes quotes, backslashes, tab and other control characters, so the body holds a different string. Tested with the real kit: secrets file lines pa"ss\word99, SUPERSECRET123 and a PEM block; the block printed replaced=5 and exited 0, but the file it named (and a fake local endpoint received) contained the escaped password intact while the step reported success. The text says no recipe text is sent before it has passed through redact, which does not hold, and the destination is the external host pi.ruv.io. — fix: Redact the recipe fields before JSON-encoding them: write the raw fields to $E, redact that file, and build the JSON body from the redacted text with node -e (JSON.stringify) into the file that is POSTed. Alternatively, after redacting, JSON.parse the body and refuse to send if any secret still appears in a decoded string value. Add a test with a secret containing a quote and a backslash.
