# Contracts — 2026-10-26-bbs-ai-design-skills

Written by the lead before any build. Each power becomes **one kit verb**: deterministic, no network, no new
dependency, Node 20+ built-ins only. The `integration` stream later wires each verb into the workflow steps approved
at the verdict (see `.claude/bbs/runs/2026-10-26-ai-design-skills/integration.md`), gated to UI, landing page or
animation tasks.

## Shared conventions (every stream)

- Module: `src/lib/kit/<module>.js`, exporting `verb`, `usage` and `async run(args, io)` like `src/lib/kit/render.js`.
  Copy it **verbatim** to `.claude/helpers/kit/<module>.js` (the installed copy this repo runs; `cli.js` loads every
  module there by its `verb` export). Export the pure functions too, so unit tests import them.
- Input: a JSON file (`--file <f>`) or stdin, at most 8 MiB; reject unknown top-level keys and wrong types with
  `KitExit` code 1 and a message naming the field. Output: one JSON object on stdout (return it from `run`), or
  `{ raw }` for emitted code/CSS text when the usage says so.
- Exit codes: 0 ok; 1 invalid input or broken state (`KitExit(msg, 1)`); 2 only for a verb whose usage says it is a
  judge and the product fails its bar (return `{ ..., exit: 2 }`), and then add the verb to the `PRODUCT_JUDGES` list in
  `exit-codes.js` (both copies). Never 2 for a tool limit.
- Writes (only where the contract says `--out`): temp file + rename, like render.js; never follow a symlink.
- Header comment: what the verb does in our words, and "Built from ideas audited by /w-bbs (run
  2026-10-26-ai-design-skills); no foreign code." Never copy text or code from the fetched source (do not read it).
- Tests: `test/kit-<stream>.test.js` (unit, imports from `src/lib/kit/`) and the packaged check
  `test/kit-<stream>-packaged.test.js` (uses `test/helpers/packaged.js`: `installPackaged()`, drives the INSTALLED
  `cli.js`, asserts `help` lists the verb, a happy path, a bad input exiting 1, and `pkg.egress()` is empty).
  Use a fresh temp dir per test run, removed afterwards.
- Run `node --test test/kit-<stream>.test.js test/kit-<stream>-packaged.test.js test/kit-infra.test.js` before
  reporting. All green, nothing skipped, no assertion weakened.
- Commit in the stream worktree with a clear message.

| reference-frame-fidelity-check | `fidelity.js` / `fidelity` (a **judge**) | `fidelity --ref <a.png> --actual <b.png> [--regions <f.json>] [--target 30] [--region-target 28] [--blur 1] [--diff-out <d.png>]`. Own minimal PNG decoder/encoder with `node:zlib` (8-bit gray, gray+alpha, RGB, RGBA, palette; non-interlaced; reject 16-bit/interlaced with KitExit 1 and a clear message). Composite alpha on white. Box or gaussian blur of radius `--blur` on both, luminance-weighted PSNR (dB; identical → `Infinity` reported as `null` with `identical:true`). Regions `[{id, x, y, w, h, target?}]` scored separately; a region below target is retried at blur×3 and reported as `structural_psnr`. Sizes must match (else exit 1). Returns `{psnr, target, pass, regions:[{id, psnr, structural_psnr?, target, pass}], diff_out?}`; **exit 2 when the frame or any region fails** (add `fidelity` to PRODUCT_JUDGES). `--diff-out` writes an amplified absolute-difference PNG (×4, clamped). Tests build PNGs in memory with the encoder. |
| layer-export-placement-math | `layer-place.js` / `layer-place` | `layer-place --file f`. Input `{frame:{x,y}, layers:[{id, z, bounds:{x,y,w,h}, render_bounds?:{x,y,w,h}, image?:{w,h,scale}, clipped_by_parent?:bool, effects_even?:bool, stroke_geometry?:{x,y,w,h}, shape?:"arc"\|"rotated"\|"mask"\|"plain", children_move?:bool}]}`. Decision table, in order: shape arc/rotated/mask → `absolute-bounds` (export with absolute bounds, place at bounds); image matches render_bounds (at scale, ±1px) → `render-bounds`; clipped_by_parent or effects_even → `overhang-offset` (offset by the overhang between render_bounds and bounds); uneven overhang with stroke_geometry → `stroke-geometry`; else `bounds` with a warning. Positions are relative to the frame. `children_move` → `{rebuild_container_in_css:true}`. Output sorted by original z, `{placements:[{id, rule, left, top, width, height, z, why}], warnings}`. |
| sacred-background-preservation | `bg-fill.js` / `bg-fill` | `bg-fill css --file f`: input `{selector, container:{w,h}, image:{w,h}, scale_mode:"FILL"\|"FIT"\|"TILE"\|"STRETCH"\|"CROP", transform?:[[a,b,tx],[c,d,ty]], tile_scale?}` → `{css:{"background-size","background-position","background-repeat"}, raw_css}` reproducing the fill (CROP uses the 2×3 transform; reject a rotated/skewed transform with exit 1). `bg-fill guard --file <css> --selector <sel>` (a **judge**): exit 2 when any rule or `@keyframes` used by that selector changes `background`, `background-image`, `background-position`, `background-size`, `filter` on the background element, or replaces the image with a flat colour; frosted panels must use a sibling layer (`backdrop-filter` on the background selector itself is a finding). Returns `{violations:[{line, property, why}], pass}`. Add `bg-fill` to PRODUCT_JUDGES (guard only exits 2). |
| entrance-choreography-kinds | `entrance.js` / `entrance` | `entrance --file f [--stagger-ms 60] [--container-stagger-ms 120]`. Input `{groups:[{id, kind:"card"\|"text"\|"icon"\|"bar"\|"rule"\|"photo"\|"chip"\|"chart"\|"other", order:n, covered?:bool, items?:n}]}`. Catalogue as data: card → rise 16px + blur 8→0 + fade; text → rise 6px + blur 2→0; icon → fade + scale 0.9→1 (never 0); bar/rule → grow from start edge (scaleX 0→1 with transform-origin start: the only allowed zero scale is a 1-D grow); photo → shimmer then sharpen (blur 12→0); chip → fade + rise 4px; chart → draw/grow; other → fade. Containers staggered in reading order, items within by `--stagger-ms`; covered groups enter last and are listed first in `exit_order`. Returns `{timeline:[{id, kind, delay_ms, duration_ms, from, to, easing}], exit_order:[...], css}` where `css` is ready-to-paste keyframes. Reject scale 0 for non-1-D kinds. |
| keyframe-track-story-engine | `keyframes.js` / `keyframes` | Pure engine: `evaluate(track, t)` with tracks `[{t:ms, v:number\|number[], ease?:"linear"\|"in"\|"out"\|"in-out"\|cubic-bezier [x1,y1,x2,y2]}]`, loop length `L`, values interpolated per segment. `keyframes check --file f` validates `{loop_ms, stories:[{id, card, pattern, sentence, offset_ms?, tracks:{<prop>:[...]}}]}`: every track starts at t=0 and ends at t=loop_ms with the SAME value as t=0 (design state, seamless loop) else a finding; times strictly increasing; one-sentence `sentence`; two stories on different cards with equal offsets → warning "acts in unison". Returns `{ok, findings, warnings}` (exit 0; `ok:false` when findings). `keyframes sample --file f --at <ms>` returns every property's value at that time. `keyframes emit` returns `{raw}`: a small standalone ES module (our own code) with `evaluate`, `ease` and `createLoop(stories, {loop_ms, now})` that drives values from one shared clock (`requestAnimationFrame`, injectable `now`). A `patterns` sub-command lists the story pattern menu as data (stack-landing, scrubber-glide, donut-ease-out, typed-prompt, marquee-one-set, counter-tick, pulse-highlight). |
| deterministic-frame-capture | `frame-capture.js` / `frame-capture` | `frame-capture plan --fps 30 --frames <n> [--warmup <n>] [--loop-ms <ms>]` returns `{steps_ms:[...integers], frames:[{index, t_ms, loop_t_ms}], mean_fps}`: whole-millisecond steps whose running sum stays within 1 ms of index×1000/fps (e.g. 33,33,34 for 30 fps), loop time = t mod loop_ms, warm-up frames excluded from the list. `frame-capture seam --file <manifest.json> --loop-ms <ms>` checks a saved manifest: first and last-plus-step loop times meet at the seam, no duplicate or missing loop time. `frame-capture capture --url <url> --out <dir> --fps --frames [--width --height --scale]`: only `file://` or `http://localhost`/`127.0.0.1` URLs (anything else exit 2 refused, never fetched); loads `playwright` only if it can be resolved from the project (**not** added to package.json; missing → return `{captured:0, reason:"playwright not installed: frame-capture capture needs it", exit:4}`, exit 4 being the precondition class in `exit-codes.js`), installs a fake clock, steps it by the planned steps, pauses CSS animations at the matching time, screenshots each frame to `<out>/frame-00001.png` and writes `<out>/manifest.json` with each frame's loop time. Unit tests cover plan/seam/URL refusal; capture is tested only when playwright resolves (skip-with-reason is NOT allowed: test the "not installed" path by a fake resolver instead). |
