# /w-bbs — beg, borrow, steal: absorb a power from an outside source

Marathon run: `2026-10-07-bbs`. Clean-room rebuild from the write-up of the chief-of-staff `/bbs`
(first run: 12 powers found, 10 approved, 0 shipped, 18.6M tokens). No chief-of-staff code is
used or available. Everything below is a contract; the streams build it in order.

## What it does

`/w-bbs <source>` takes one source — a git repository URL, a web page URL, a local path, or pasted
text — and:

1. **Intake** — classifies the source, computes its identity, checks the registry so the same
   source at the same commit is never audited twice.
2. **Fetch** — GET only, no body, no auth header, private hosts and private redirects refused,
   25 URLs / 20 MB per run, every request logged. Repositories are shallow-cloned with tags and
   hooks off. Foreign code is **never executed**.
3. **Inventory** — helper agents read the source and return JSON only: at most 12 powers, each
   with an `idea` written in our words (the seed for a clean-room rebuild).
4. **Harness map** — indexes what the harness already has (commands, skills, helpers, hooks,
   library modules, scripts) and finds the 5 nearest tools per power by IDF-weighted cosine, the
   power's name weighted 3×. A helper judges only those 5: `have`, `partial` or `missing`.
5. **Verdict gate** — `legalVerdicts` + `defaultVerdict` per power from the licence policy and
   the sandbox check; a separate probe looks for hidden network calls on every `use` candidate;
   one table, one question (the only approval before a build); every decision recorded with a
   label (approve = 1, skip = 0).
6. **Hand-off** — approved powers become streams of a `/w-marathon` run with a 5-check finish
   line each (`tests_green`, `egress_zero`, `six_sigma_claim`, `callers_ge_1`, `packaged_check`)
   written **before** the build; one brief per power, idea-only, no source code.

The four verdicts, in order of preference: `rebuild` (always legal, preferred) · `use` (permissive
licence **and** sandbox present **and** probe clean) · `buy` (memo only; commercial, or a free
service that moves our data off the machine) · `skip` (always legal; default for a duplicate).
Two rules cannot change: **safety first** and **our rules always win**.

## CLI — `node .claude/helpers/bbs/cli.js <verb> [--run <id>]`

All verbs: JSON to stdout, `fail(msg)` → stderr + exit 1; exit 2 is reserved for "refused by
policy" (private host, limit hit, illegal verdict). Every verb re-renders `status.md`. Without
`--run`, the ACTIVE run is used. `--project <dir>` overrides the project root (tests use it).

| Verb | Does |
|------|------|
| `intake <source> [--paste-file <p>] [--slug <s>]` | classify → `repo \| url \| local \| paste`; identity (repo: HEAD sha once known, local git: `rev-parse HEAD`, local dir: sha256 of a sorted path+size manifest, paste: sha256 of content, url: `pending` until fetch); registry lookup → `{runId, type, ref, identity, known, reuse_from}`; creates the run dir and `source.json`; sets ACTIVE |
| `fetch [--max-bytes n] [--max-links n]` | url: GET-only fetch with the guards below, body saved to `fetched/<n>.<ext>`, identity finalised to sha256(body); repo: `git clone --depth 1 --no-tags -c core.hooksPath=/dev/null` into `fetched/repo`, identity = HEAD sha; local/paste: nothing to fetch, records a zero-egress row. Prints the **egress line**: `requests=<n> bytes_in=<n> bodies_sent=0 hosts=<a,b>`. On any failure stores nothing new and exits non-zero |
| `inventory --brief` | prints the helper brief: what to read, the JSON shape, the 12-power cap, "JSON only" |
| `inventory --from <file>` | validates helper JSON against the power schema; caps at 12 and marks the rest `not_inventoried`; writes `powers.json`; non-JSON or a schema miss → exit 1 with the offending field |
| `map` | builds `harness-index.json` from the project (see Harness index) and `map.json` with the 5 nearest tools per power + scores |
| `map --from <file>` | records helper judgments `{ "<power>": "have\|partial\|missing" }` into `map.json`; a judgment for a tool not in the candidate list is refused |
| `verdict` | computes `legal`, `default` and `reasons` per power; prints the verdict table (markdown) and the JSON |
| `verdict --probe <power>=clean\|found\|incomplete` | records the network-probe result; `found` or `incomplete` removes `use` with a reason |
| `verdict --decide <power>=<verdict>` / `--from <file>` | records the decision (must be legal) and the label row; writes `verdicts.json`; appends the registry row when every power has a decision |
| `handoff [--marathon]` | writes `handoff.json` + `briefs/<power>.md` for every approved power; with `--marathon` and `.claude/helpers/marathon/cli.js` present, creates the marathon run (`init bbs-<slug>`), writes its `finish-line.json` lines and `kickoff.md`, and adds one queued stream per power; prints the resume line |
| `status [--next]` | renders `status.md`; `--next` names the next verb to run |
| `report` | one line: `found=<n> approved=<n> skipped=<n> buy=<n> marathon=<run-id or none>` |

### Fetch guards (code, not advice)

- Method GET, no body, no `Authorization`/`Cookie` headers; `User-Agent: danizee-claude-suite-bbs`.
- Host check **before connect and on every redirect hop**: resolve with the injected `lookup`
  (all addresses) and refuse loopback (`127/8`, `::1`), private (`10/8`, `172.16/12`,
  `192.168/16`, `fc00::/7`), link-local (`169.254/16`, `fe80::/10`), unspecified (`0.0.0.0`,
  `::`), and IPv4-mapped IPv6 (`::ffff:a.b.c.d` checked as the IPv4 inside). Literal IP hosts are
  checked without DNS. `localhost` and `*.localhost`/`*.local`/`*.internal` names are refused.
- Redirects: max 5, each hop re-checked; a redirect to a private host is a refusal, not a follow.
- Limits per run: 25 URLs, 20 MB total body bytes; a response over the remaining allowance is
  aborted and refused. Timeout 30 s per request.
- Every request appends an `egress.jsonl` row: `{ts, kind: "http"|"git", method: "GET", url,
  host, status, bytes_in, bytes_out: 0, refused?: reason}`.
- Cited links in fetched pages are recorded in `source.json.cited` and **never fetched**. No crawl.
- `git clone` runs with `GIT_TERMINAL_PROMPT=0`, `--depth 1 --no-tags`, `core.hooksPath` to an
  empty temp dir, and the same host check on the clone URL's host. Only `https://` and `git@…`
  shapes the owner typed.
- Injection points for tests: `fetchImpl`, `lookup`, `git` (runner), `now`. The default
  implementations are Node's `fetch`, `dns.promises.lookup` and `child_process.execFileSync`.
- Known gap (documented, not fixed): DNS rebinding between check and connect. The sandbox is the
  hard boundary; this run ships no sandbox, so `use` is removed when none is present.

### Power schema (`inventory --from`)

```json
{ "name": "kebab-or-words", "what": "one sentence", "evidence": "file path or quote location",
  "dependencies": ["…"], "data_needed": "none|…", "network": "none|outbound|inbound|unknown",
  "size": "small|medium|large", "licence": "SPDX id or unknown", "idea": "the power in our words" }
```

All nine fields required; `network` and `size` are enums; `name` unique within the source. Input
is `{ "powers": [...] }` or a bare array. More than 12 → the first 12 are kept and
`not_inventoried: [names…]` records the rest.

### Harness index (`map`)

Index rows `{ id, kind, name, path, text }` from: `.claude/commands/**/*.md` (kind `command`),
`.claude/skills/*/SKILL.md` (skill), `.claude/helpers/**/*.js` (helper), `.claude/hooks/*.sh`
(hook), `src/lib/**/*.js` and `src/plugins/*.js` when present (module), `scripts/**` and
`package.json` scripts (script). `text` = name + first 80 lines, lower-cased, tokenised on
non-alphanumerics, stop-words removed. `matchPower(power, index)` → top 5 by cosine over IDF
weights (`idf = ln((N+1)/(df+1)) + 1`), the power's `name` tokens counted 3×, ties broken by
name. Scores are rounded to 3 decimals and stored. No LLM in `map`; the judgment is `map --from`.

### Licence policy (`verdict`)

| Class | SPDX ids (case-insensitive) | Legal verdicts |
|-------|-----------------------------|----------------|
| permissive | MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, 0BSD, Unlicense, CC0-1.0, Zlib, BlueOak-1.0.0 | rebuild, use*, skip |
| copyleft | GPL-*, LGPL-*, AGPL-*, MPL-2.0, EUPL-*, CC-BY-SA-*, SSPL-*, OSL-* | rebuild, skip |
| commercial | Commercial, Proprietary, BUSL-*, Elastic-*, "all rights reserved" | buy, rebuild, skip |
| none / unknown | anything else, empty, `unknown` | rebuild, skip |

`*use` also requires `sandboxPresent === true` (detect: `docker` on PATH **and** `docker info`
exits 0, or `unshare` on Linux; injected for tests) **and** probe `clean`. Each removal carries a
reason string. `defaultVerdict`: `skip` when map status is `have`; `rebuild` when legal; else the
first legal verdict in preference order; `buy` only when the class is commercial or the power's
`data_needed` moves data off the machine and `network` is `outbound`. Decisions outside `legal`
are refused with exit 2. Labels: `labels.jsonl` rows `{ts, run, power, verdict, label}` where
`label = verdict === 'skip' ? 0 : 1`.

### Hand-off (`handoff`)

For every power with verdict `rebuild` or `use` (a `buy` gets a memo in `briefs/`, no stream):

- `briefs/<power>.md` (`renderBrief`): the idea in our words, provenance (source ref, identity,
  licence, verdict, run), what we have / partial, the 5 finish-line checks, the kickoff lines,
  the never lines, and — for `use` — the wrapping rule (behind our interface, our tests, in the
  sandbox). Never includes source code.
- `buildFinishLine(powers)` → marathon lines: `tests_green_<p>` (`runs.streak:unit`, at_least 1),
  `egress_zero_<p>` (`measure:egress_zero_<p>`, bool is true), `six_sigma_<p>` (`reviews.streak`,
  at_least 2), `callers_<p>` (`measure:callers_<p>`, number at_least 1), `packaged_<p>`
  (`measure:packaged_<p>`, bool is true). Power ids are slugified to `[A-Za-z0-9_-]`.
- `--marathon`: `marathon/cli.js init bbs-<slug>`, then write `finish-line.json` (tolerance from
  `.claude/marathon/finish-line.example.json` when present, else 0/2/5/2) with the per-power lines
  plus the standard `clean_reviews`, `latest_high`, `open_high`; fill `kickoff.md` from
  `handoff.json`; `cli.js stream <power> state=queued plan=<brief path> next="…"`. Prints
  `/w-marathon --resume <run-id>`. When the marathon helpers are absent it says so and exits 1.
- `handoff.json`: `{ run, source, marathonRun|null, powers: [{ name, verdict, brief, lines }],
  memos: [...] }`.

## Command markdown — `/w-bbs <source>` · `/bbs`

Phases (each a `cli.js` verb; the command never computes a verdict or an identity in chat):

0. **Intake** — `cli.js intake <source>`; if `known`, say which run it reuses and jump to 5.
1. **Fetch** — `cli.js fetch`; print the egress line verbatim; on failure stop.
2. **Inventory** — `cli.js inventory --brief` → helpers on `haiku` (one per ≤ 15 files or per
   page) read the fetched source and return JSON only; concatenate → `cli.js inventory --from`.
3. **Map** — `cli.js map` → one `haiku` helper judges each power's 5 candidates → `cli.js map --from`.
4. **Verdict** (the only approval) — `cli.js verdict`; for each `use` candidate spawn one probe
   helper on `sonnet` that returns `clean|found|incomplete` with evidence → `cli.js verdict
   --probe`; show the table; **one** AskUserQuestion; `cli.js verdict --from`.
5. **Hand-off** — `cli.js handoff --marathon`; print the resume line; `cli.js report`.
6. **Compound** — `/bc`.

Rules: never execute fetched code · GET only · JSON only from helpers · one approval · never
crawl · `--resume <run-id>` continues from `status --next` · `--status` prints status only.
Model policy: inventory and map helpers on `haiku`, probes on `sonnet`, lead on the session model.

`measure:packaged = true` only when run through the marathon ledger by the lead.
